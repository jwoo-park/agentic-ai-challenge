# 평가 기록 보관소 (evaluation archive)

이 폴더는 이미 수행한 평가 결과를 보존하기 위한 것이며, 기획안의 일부가 아니다. 새 버전의 독립 평가 단계에서는 이 폴더 및 이전 평가·점수·개선 권고를 열람하지 않는다. 새 평가를 확정한 뒤 사용자가 명시적으로 비교를 요청한 경우에만 과거 보고서를 열람한다. 루트의 [AGENTS.md](../AGENTS.md)에 평가 격리 규칙과 고정 루브릭을 기록했다.

보고서는 2026-11-25 채팅에서 제공한 평가 내용을 Markdown으로 정리한 보존본이다. 새로 채점하지 않았으며 UI 그래프는 표로 대체했다. 외부 서비스 설명은 당시 평가에서 언급한 비교 내용으로, 이번 보관 작업에서 재검증하지 않았다.
