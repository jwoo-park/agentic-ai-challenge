V4는 V1보다 10.75점, V2보다 10.5점, V3보다 4점 높다. V3→V4의 순증가는 도구 역할·선택 조건 +1, 검증 실패 후속 행동 +0.5, 범위 적절성 +1.25, 전달력 +1.25로 구성된다. 나머지 18개 세부 항목의 등급은 동일하다. 상황 대응은 동일 등급 내에서 설계가 개선되었다(완료된 단계의 재판단, 저장 실패 재처리, 평가 모델 실패 재시도). V3에서 이미 높은 등급을 받은 항목은 같은 점수를 유지했다.

## 쌍대 비교

- V1 vs V4: V4 우세. V1은 실제 기여와 근거 연결, CV/소개 활용에 집중했다. V4는 이 기록을 프로젝트 진행 판단, 후속 작업 및 산출물 갱신에 활용한다. V1의 CV 연결과 여러 날짜의 동일 작업 블록은 V4 본문에서 명시적이지 않으므로 유지 여부를 단정하지 않는다.
- V2 vs V4: V4 우세. V2의 공개 포트폴리오와 자료 관리 UI의 구체성은 강점이다. V4는 기록이 계획 및 결과물에 미치는 영향과 행동 선택을 설명한다. V2의 중복 사본 삭제 승인, 상세 편집 UX는 V4에서 강조가 줄었다.
- V3 vs V4: V4 우세. V3는 계획과 실제 작업의 연계 및 재계획을 확립했다. V4는 산출물·진행·로그를 하나의 창에서 연결하고, 기존 시연 완료 상태를 새 조건에 따라 재판단하며, 연결 자료 우선 조회→추가 탐색→종료→저장 후 재확인을 명시했다. 독립 평가 실패 재시도, 점수 범위/합계 검증, 채택 의견의 작업 연결도 추가됐다. 독립 평가 기능 자체가 핵심 점수 상승의 주된 원인은 아니다.

## 퇴행 검증

유지/강화: 사용자 한 줄 입력, 계획-작업 연결, 완료 조건, 근거와 개인 기여 구분, 공개 승인, 독립 평가 입력 고정 및 결과 비교, 사용자 채택 후 계획 반영.
V4에서 명시가 줄어든 항목: V3의 다중 프로젝트 전체 대시보드, 유형별 프리셋 편집과 모델 선택 UI, 장기 개인 작업 방식 학습, 캘린더 등록 실패 대응. V4는 캘린더 및 필요시 검수/독립 평가를 언급하지만 각 기능의 상세 설계를 현재 문서에서 모두 설명하지 않는다. 삭제되었다거나 동일하게 작동한다고 단정하지 않는다. V1의 작업 블록/CV 및 V2의 상세 자료 관리·공개 보고서 편집 UX 역시 V4의 핵심 시연에서 비중이 감소했다. 범위 축소 자체는 핵심 Agentic 설계를 강화하는 방향이며 해당 기능을 필수 복원할 필요는 없다.

## 핵심 구조 변화

V1: 작업 자료 → 의미적 작업 연결 → 개인 기여 → 소개.
V2: 자료 관리 → 작업 로그/개요 → 공개 보고서.
V3: 목표·계획 → 실제 작업 확인 → 상태/완료 조건 판단 → 재계획.
V4: 작업/변경 결정 → 연결 정보 및 추가 영향 탐색 → 계획·후속 작업·산출물 갱신 → 결과 검증 → 근거 기반 소개.

V4의 구별되는 설계는 프로젝트 변경의 영향 범위를 추적하고 여러 표현(계획·기록·산출물)의 일관성을 유지하는 데 있다. 자료가 있다는 사실과 현재 요구사항을 충족하거나 결과물에 반영됐다는 사실을 구분하는 UI가 효과적이다. 시장 차별성이나 실사용 성능은 입증되지 않았다.

## 남은 개선 사항
- P0: 재조회에서 불일치를 발견하면 수정 대상 식별, 수정/재조회, 미해결 상태 표시로 이어지는 검증 실패 처리 명시.
- P1: 간접 영향이 여러 단계에 걸친 경우 탐색 범위/종료 조건, 근거 충돌 시 보류/확인 기준 정의. 정답 영향 목록을 작성해 범용 Agent와 같은 입력·권한·모델 조건에서 비교.
- P2: 5분 발표에서는 기존 영상 시연 완료→HTML로 결정 변경→완료 상태 재판단→리허설/발표 자료 수정 위치→저장 후 확인을 하나의 사례로 전달. 별도 영상 제출 요건은 유지되는 예외로 사용. 문제 해결 사례 및 소개·독립 평가 기능은 보조 기능으로 제시.
- 새 기능을 확장하기보다 현재 V4를 제출본의 기반으로 선택하는 것이 적절하다.

## 한계
동일 평가자에 의한 문서 기반 비교이며 통계적 독립 평가가 아니다. 각 버전의 가상 스트레스 테스트는 구성이 다르므로 통과 개수를 동일 벤치마크처럼 비교하지 않았다. HTML 및 실제 모델 실행, 시장 서비스 최신 기능, 최종 제출 PDF는 검증하지 않았다. 수상 가능성을 추정하지 않는다.
